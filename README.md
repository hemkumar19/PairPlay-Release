## 📱 How to Install on Android

1. **Download the APK** using the button above or directly from your phone browser.
2. When prompted by Android:
   - Tap **Settings** ➜ **Allow from this source** (or *Install unknown apps*).
3. Open the downloaded `PairPlay-latest.apk` file and tap **Install** (or **Update**).
4. Launch **PairPlay** and enjoy with your partner! ❤️
